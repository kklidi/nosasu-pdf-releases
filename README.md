# NOSASU PDF 공식 다운로드

이 저장소는 Windows용 **NOSASU PDF 배포 파일 전용**입니다. 애플리케이션 소스 코드는 이 저장소에 포함하지 않습니다.

## 다운로드

[최신 버전 다운로드 페이지 열기](https://github.com/kklidi/nosasu-pdf-releases/releases/latest)

일반 사용자는 릴리스의 `NOSASU-PDF-버전-windows-setup.exe`를 받으세요. 설치 없이 사용하려면 `windows-portable.exe`를 받으면 됩니다.

- 설치형: Windows에 앱과 바로가기를 설치하며 지속적인 업데이트 사용에 권장합니다.
- 포터블: 설치하지 않고 EXE를 직접 실행합니다.
- `windows.sha256`: 다운로드 파일의 SHA-256 확인값입니다.
- `notices.zip`: 오픈소스 라이선스·저작권·보안 안내입니다.

## 업데이트와 보안

v0.5.0부터 앱에서 GitHub 기반 새 버전 확인과 서명 검증 업데이트를 지원합니다. PDF 파일과 문서 암호는 업데이트 서버로 전송되지 않습니다. Windows 코드 서명 인증서는 아직 적용하지 않았으므로 SmartScreen에 게시자 경고가 표시될 수 있습니다.
