# NOSASU PDF 공식 다운로드

NOSASU PDF는 무료 Windows PDF 편집기입니다. 개인·업무·상업 목적으로 무료로 사용할 수 있습니다.

## 다운로드

[최신 릴리스](https://github.com/kklidi/nosasu-pdf-releases/releases/latest)의 Assets에서 이름이 `-windows-setup.exe`로 끝나는 설치 파일 하나만 받아 실행하세요. `latest.json`은 앱의 업데이트 확인에 쓰는 기술 파일이라 받을 필요가 없습니다.

- 다른 사람에게 알릴 때는 **이 페이지 주소를 공유**해 주세요. 설치 파일을 다른 곳에 올리거나 고쳐서 배포하는 것은 허용하지 않습니다(사용권 계약 제2조). 다른 곳에서 받은 파일은 변조됐을 수 있습니다.
- 0.6.0 이상을 쓰고 있다면 앱의 `업데이트 확인`으로 새 버전을 받을 수 있습니다.
- 0.5.8 이하를 쓰고 있다면 업데이트 서명 키가 0.6.0에서 바뀌어 자동 업데이트가 되지 않습니다(`입력을 확인하세요.`가 표시됨). 최신 설치 파일을 한 번 직접 실행하면 설치된 앱 위에 업데이트되고, 그 뒤로는 자동 업데이트를 쓸 수 있습니다.

정확한 최신 버전과 파일 이름은 항상 최신 릴리스 페이지에서 확인하세요. 이 안내에는 버전 번호를 고정하지 않습니다.

## SmartScreen 경고

현재 Windows 코드 서명(Authenticode) 인증서를 적용하지 않아 설치할 때 "Windows의 PC 보호" 또는 "알 수 없는 게시자" 안내가 표시될 수 있습니다. 이는 인증서 미적용에 대한 안내이며, 악성코드 여부를 보증하거나 면제하는 문구가 아닙니다. 반드시 이 공식 릴리스 페이지에서 받은 파일만 실행하세요. 안내가 나오면 [추가 정보] → [실행]을 누르면 설치됩니다.

## 개인정보와 네트워크

PDF는 PC 안에서만 처리되며 서버로 올라가지 않습니다. 앱은 계정·로그인이 없고 사용 기록을 수집하지 않습니다. 업데이트 확인을 쓰면(자동 확인은 기본 꺼짐) GitHub의 공개 파일만 확인하며, GitHub에는 일반적인 접속 기록이 남을 수 있습니다.

## 사용권과 면책

사용권 계약 전문과 오픈소스 라이선스는 앱의 `사용법 → 저작권 및 오픈소스 라이선스`에서 볼 수 있습니다. 소프트웨어는 "있는 그대로" 무상으로 제공되며, 법이 허용하는 범위에서 사용으로 생긴 손해에 책임지지 않습니다. 중요한 문서는 원본을 보관하고, 저장·암호·도장 결과를 직접 확인한 뒤 사용하세요.

이 저장소는 배포 전용이며 앱 소스 코드는 공개하지 않습니다. GitHub가 자동으로 표시하는 `Source code (zip/tar.gz)`에는 이 안내문만 들어 있습니다.
