# NOSASU PDF 공식 다운로드

일반 사용자는 [최신 릴리스](https://github.com/kklidi/nosasu-pdf-releases/releases/latest)에서 이름이 `-windows-setup.exe`로 끝나는 설치 파일 하나만 받으면 됩니다.

> **0.5.8 이하 사용자는 0.6.0 Setup 파일을 한 번 직접 내려받아 설치하세요.** 업데이트 서명 키가 0.6.0에서 다시 발급되어 0.5.8 이하 앱의 자동 업데이트로는 0.6.0을 설치할 수 없습니다. 0.6.0을 기존 설치 위에 설치하면 되고, 이후 버전부터는 자동 업데이트가 다시 동작합니다.

> **0.5.3 사용자는 0.5.4 Setup 파일을 한 번 직접 내려받아 설치하세요.** 업데이트 서명 키가 0.5.4에서 교체되어 0.5.3 앱의 자동 업데이트로는 0.5.4를 설치할 수 없습니다. 0.5.4 설치 후 후속 버전부터 자동 업데이트를 다시 사용할 수 있습니다.

- `NOSASU-PDF-…-windows-setup.exe`: Windows 설치형
- `latest.json`: 앱 자동 업데이트용 기술 파일이며 직접 실행하지 않습니다.

정확한 현재 버전과 설치 파일 이름은 항상 최신 릴리스 페이지에서 확인하세요. 이 README에는 버전 번호를 고정하지 않아 새 배포와 안내가 어긋나지 않도록 관리합니다.

이 저장소는 배포 전용입니다. 앱 소스 코드는 비공개 원본 저장소에서 관리하며, GitHub가 자동으로 표시하는 `Source code (zip/tar.gz)`도 이 공개 저장소의 README 스냅샷만 포함합니다.

## SmartScreen 경고

현재 Windows Authenticode 인증서를 적용하지 않아 게시자 확인 경고가 표시될 수 있습니다. 이는 인증서 미적용에 대한 경고이며 악성코드 여부를 보증하거나 면제하는 문구가 아닙니다. 반드시 위 공식 GitHub 릴리스에서 받은 파일만 실행하세요.

PDF는 앱 내부에서 로컬 처리되며 서버로 업로드되지 않습니다. 업데이트 확인을 켜면 앱은 GitHub의 공개 기술 파일만 확인합니다.
