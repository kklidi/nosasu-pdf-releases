# NOSASU PDF 공식 다운로드

일반 사용자는 [최신 릴리즈](https://github.com/kklidi/nosasu-pdf-releases/releases/latest)의 설치 파일 하나만 받으면 됩니다.

- `NOSASU-PDF-0.5.0-windows-setup.exe`: Windows 설치형
- `latest.json`: 앱 자동 업데이트용 기술 파일이며 직접 실행하지 않습니다.

이 저장소는 배포 전용입니다. 앱 소스 코드는 비공개 원본 저장소에서 관리하며, GitHub가 자동으로 표시하는 `Source code (zip/tar.gz)`도 이 공개 저장소의 README 스냅샷만 포함합니다.

## SmartScreen 경고

현재 Windows Authenticode 인증서를 적용하지 않아 게시자 확인 경고가 표시될 수 있습니다. 이는 인증서 미적용에 대한 경고이며, 악성코드 여부를 보증하거나 면제하는 문구가 아닙니다. 반드시 위 공식 GitHub 릴리즈에서 받은 파일만 실행하세요.

PDF는 앱 내부에서 로컬 처리되며 서버로 업로드되지 않습니다. 이후 버전은 앱의 updater가 GitHub 기술 파일을 확인합니다.
